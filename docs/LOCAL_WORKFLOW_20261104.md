# 本机使用与课程处理

## 准备素材

在「课表设置」填写学期起始日期和每周课程，或导入 JSON、CSV、ICS。到「素材输入」选择文件或文件夹，按课表匹配课程，确认后归档。

教材、规范、课件与练习题可以按文件页码或段落定位。录音转写结果带时间戳，可在课堂录音索引中浏览。

## 配置模型与处理课程

在「模型配置」选择本地或云端文本模型。云端调用使用所选接口及已批准的数据类别。使用云端知识对话时，批准对话所需的个性化数据类别。发送教材摘录时同时使用页级文本授权。

在「处理控制」选择科目后点击「运行课程流程」。流程依次处理解析、OCR、录音转写、知识点提取、引用核验和复习资料生成。分阶段的结果可以在处理日志中查看。

## 浏览和导出

在「结果输出」查看知识点及来源原文。待确认的条目可逐条人工核验，或用 Flash 按预算联网自查。生成复习产物后，可查看章节速览、背诵卡、数值对照、可搜索的 HTML 和 PDF。Anki 通过 TSV 导入。

「导出 ZIP」支持单科和全科，可附带引用源文件。「导入 ZIP」读取 FireKB 导出包，恢复知识点与证据，并跳过已有编号。编辑与导入前的备份存放在 `90_日志/_备份/`。
