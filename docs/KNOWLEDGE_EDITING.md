# 知识点编辑与批量删除

更新：2026-11-09。重启桌面端，在「结果输出」知识点浏览区使用。

## 编辑

点击知识点卡片上的「编辑」，修改标题、正文、批注、数值、重要度、章节及小节，然后点击「保存修改」。编辑表单载入知识点原始正文，支持直接填写LaTeX。更新后的批注显示在卡片中。

标题、正文、批注或数值改变后，条目进入待核验；可通过既有人工核验或AI自查流程处理。修改重要度、章节等整理信息会保留当前核验状态。保存失败保留表单，可继续重试。知识点有并发更新时会提示重新打开编辑。

## 批量删除

逐条勾选卡片，或使用「选择本页」「选择当前筛选结果」。选择可跨页累积，切换课程或筛选状态后清空选择。点击「删除所选」查看条目清单，再点击「确认删除」。取消删除会保留当前选择。

删除同步移除知识点、关联证据、核验记录、AI自查结果和质量记录；原始课程素材继续用于课程归档。列表立即刷新，对话检索随之读取最新知识库。编辑或删除后，点击「生成复习产物」更新背诵材料，再按需导出阅读版。

## 备份与验证

每次实际保存和删除前自动备份涉及的数据文件，位置为 `90_日志/_备份/knowledge_edit_*` 或 `knowledge_delete_*`。操作结果显示备份目录；其中 `manifest.json` 记录文件及SHA256，`files/` 保存操作前的数据。

写入使用项目统一写锁和事务发布。删除确认凭据绑定所选条目的当前内容，提交时重新校对。编辑后的核验门禁持续覆盖后续verify运行。
