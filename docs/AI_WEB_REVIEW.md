# 待验知识点的 AI 联网自查

2026-11-06 更新。沿用原 Electron 桌面界面、既有 DeepSeek API 和出站授权。

## 操作入口

### 在知识点浏览区人工核验

重启更新后的桌面端，在「结果输出」筛选「待人工处理」，点击条目下的「人工核验通过」。展开后核对定义、数值、附注、问题说明、引用与本地原文，再点击「确认人工核验通过」。条目立即移入已验证，显示「人工核验 · 已验证」和核验时间，并可用「人工核验」筛选单独查看。

保存时自动备份知识点、证据和审核记录；按整条知识点记录人工裁决，不伪造逐字匹配结果或 AI 评分。原文或审核状态在展开后变化时须重新核对，人工驳回不会被该入口覆盖。同内容重检保留人工结论，内容变化使旧凭据失效；后续 AI 缓存应用也不会覆盖有效的人工标识。

可连续核验多条，完成后点击「生成复习产物」更新背诵卡和 Anki；「课程阅读版 / PDF」重新生成阅读材料。新产物保留人工核验标识。人工操作本身不调用 API。

### AI 联网自查

在「结果输出」选择课程，点击「AI 联网自查」查看范围，设置本批新增数量和预算，再点击「开始 Flash 自查」。默认仅用 `deepseek-flash`，单并发、最多新增 5 条、估算费用上限 0.10 **美元**。处理控制页的「AI 自查预览」只展示计划，不请求 API。

已完成结果优先复用；预算不足或 API 返回 401/402/403 时，停止提交新任务，保存并应用已完成结果。可在同一入口续跑。程序不因核验失败自动升级模型，普通与强模型配置均已按用户要求设为 Flash。两轮使用同一模型、不同提示，不能视为两个独立模型。

CLI 对应命令：

```powershell
# 免费预览，不重检全库、不调用 API
.venv\Scripts\python.exe -B -m firekb ai-review --course FIRE-E --dry-run
# 小批自查：按明确的条数和预算执行
.venv\Scripts\python.exe -B -m firekb ai-review --course FIRE-E --limit 5 --budget-usd 0.10
# 仅应用已有有效结果并刷新材料，零 API 请求
.venv\Scripts\python.exe -B -m firekb ai-review --cached-only
```

数量限制针对新增任务；复用已有结果不收取 API 费用。`--refresh` 重新判定已有记录，可能增加费用。已有搜索/正文缓存保留 7 天，同日、同内容的完整判定可复用；新流程还会缓存每轮模型结果，避免第二轮失败后重付第一轮成本。

费用守卫按 [官方价格](https://api-docs.deepseek.com/quick_start/pricing/)（2026-11-04）峰时、不命中输入缓存的价格计算：Flash 输入 $0.30/百万 token、输出 $1.20/百万 token；Search/Fetch 均为 $0.00075/成功请求。每次请求前在互斥锁内预留费用，模型输入按 UTF-8 字节数加余量保守估计，输出按最大 token 数预留；响应后按实际 token 用量回填。异常请求按已预留费用保守记账。费用记录在 `90_日志/web-review/last-run-cost.json`，不是服务商账单；价格变动可能影响估算上限。旧流程未完整记录 token 用量，不能据此追溯此前准确花费。

## 评分与自动放行

这里的「置信度」为**可解释的证据评分**，不是经过统计校准的正确概率。

| 维度 | 权重 | 计算方法 |
|---|---:|---|
| 证据覆盖 C | 45% | 两轮均有有效正文引文的声明数 / 总声明数；网页与本地教材均可取证 |
| 来源质量 A | 20% | 实际引用的最佳网页来源：政府、院校、规范/学术机构、教材/学术出版社 1.0；搜索服务标记高权威的其他来源 0.85；其余 0.6 |
| 证据独立 I | 5% | 不同站点且正文不相同的来源数，加逐字引用的本地来源，除以 2，封顶 1 |
| 条件明确 T | 20% | 两轮适用口径相容且条件均明确为 1，否则 0 |
| 两轮一致 J | 10% | 两轮均有有效证据的声明数 / 至少一轮有有效证据的声明数 |

`S = 0.45C + 0.20A + 0.05I + 0.20T + 0.10J`。

按用户要求，v2 自动通过门槛为 **80%**，75%–80%标记为“接近通过，待复核”，仍不进入背诵。定义、每个数值和附注分别核对；同时须满足：

- 每项声明两轮均有真实正文引文；两轮完整核对定义、数字、单位、公式、条件，无未解决冲突；
- 课程例题、附注及特有数值可以由本地教材原文获证，不要求网上有一模一样的例题。一般连续引文8–600字符，数值引文4–600字符且须匹配数值及单位；
- 每轮至少一项声明有真实网页正文佐证；只有本地引文、搜索摘要、相关网页标题或模型常识不能通过联网核验；
- 取消“必须两个来源”和“必须在原始站点白名单内”的一票否决，改为评分因素；增加港澳台、英国/澳洲院校及 IAFSS 等来源识别；
- `course_material` 与 `general_principle` 可相容，通过后按课程口径标记。现行与历史规范不可混同，规范声明仍须两轮逐项联网获证；
- 本地文件定位和证据存在、内容修订号一致、没有人工驳回。

高分不能抵消关键检查失败。旧版规范若核实，仅以 `historical_standard` 标记，不能自动当作现行条款。80%为规则评分阈值；评分由覆盖度、权威性、独立性、适用性和一致性计算。

### 免费重评已有结果

```powershell
.venv\Scripts\python.exe -B -m firekb ai-review --course FIRE-G --rescore-cached --dry-run
.venv\Scripts\python.exe -B -m firekb ai-review --course FIRE-G --rescore-cached
```

`--rescore-cached` 隐含 `--cached-only`，仅使用已保存的双轮判定、原始网页正文缓存和当前课程原文，不请求 API。只重评选定课程、内容未变且未过期的记录。保留原评分、原判定说明和有效期，不把重新计算分数当作重新联网。原 API 失败记录显示“未完成/未评分”，不能凭空补审。重评前备份记录；新正文快照单独保存到日志目录，避免把全文重复塞进知识点、审核凭据和桌面返回值。

未重评的 v1 通过凭据继续按原公式和90%门槛校验，不将旧分数直接套用新门槛。桌面保留原视觉样式，并分别标示新旧规则。

## 状态、留痕与产物

AI 通过记录存于 `kp.ai_verification`、`evidence.ai_verification` 和 `audit.ai_review`；`verification_method=ai_web`。不改写原来的逐字引用匹配结果，也不伪造 `human_review` 或 `human_verified`。

原始两轮判定、声明及引用 URL 在 `30_知识点/ai_reviews.jsonl`。网页缓存、逐轮判定与 token 用量在 `90_日志/web-review/`。记录绑定定义、数值、附注、证据和本地正文哈希，有效期 30 天。内容变化或记录过期后，直接生成复习卡/导出也会拦截失效记录；重新 `verify` 将对应问题恢复待确认。完整人工裁决可以替代 AI 记录；人工驳回优先。

自查完成后自动更新各课程与全库的复习卡、Anki、Markdown 和 HTML；PDF 需使用原来的「课程阅读版 / PDF」入口或 `export --course FIRE-E --pdf`，无需调用模型。AI 条目带评分和联网来源，本地引文未精确匹配时会明示。

各课程及 `all` 输出目录新增 `10_AI联网自查报告.md`、`ai-review-report.json`。桌面可筛选「AI 已核验」「待人工处理」，展开查看原因和来源。人工工作表也附自查结果，`ok / bad / skip` 用法不变。
