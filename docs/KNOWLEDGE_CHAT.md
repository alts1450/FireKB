# 知识库对话

更新：2026-11-09。侧边栏第一行「知识对话」打开对话页，沿用原桌面端样式。

## 对话与引用

- 选择模型、推理强度和课程范围后提问。默认 DeepSeek Flash、关闭推理；Pro 已禁用。
- Enter 发送、Shift+Enter 换行。支持连续追问、停止生成、新对话。设置对下一次发送生效。
- 有有效知识点引用的原文、解释、归纳和计算统一显示绿色，悬停或键盘聚焦查看知识点名称、来源、页码和原文。
- 普通标题、序号、衔接文字使用正常颜色；知识库之外的知识和联网补充使用黄色。
- 回答下方分别显示检索条数与实际采用的不同知识点数。
- 回答直接给出结论、依据、计算或步骤。具体适用条件随相关结论说明。

## 划选、批注与收录

1. 用鼠标选中回答中的文字，点击「收录选中文字」。支持半句、跨段选择，选中公式时保留整条公式的 LaTeX。
2. 选择课程，编辑标题和正文，填写批注。也可使用「批注 / 收录知识点」勾选整段。
3. 点击「人工核验并收录」，知识点进入已验证列表，标记「人工核验、来源：网络」。

收录在本机完成，重复点击复用已存条目；失败时保留编辑内容。保存后可用于对话检索，重新生成复习产物后进入背诵卡和导出资料。正文、批注或来源变化后需重新核验。

回答快照在 `90_日志/chat-answers/`，收录原文归档在 `10_原始归档/网络/课程ID/`。记录包含原对话、所选字符范围及实际联网链接。

## 检索与模型调用

使用开源 [assistant-ui LocalRuntime](https://www.assistant-ui.com/docs/runtimes/custom/local-runtime) 管理消息、取消和会话。Electron IPC 调用现有 Python API 层，密钥留在主进程侧。

检索优先使用当前问题，短指代追问补入上一轮问题。多题分别排序并轮流选取知识点，一般取8条，多题最多24条。检索检查核验凭据和原文，局部抽取批次通过精确引文匹配后可供对话使用，来源提示为「局部抽取 · 原文已定位」。课程批次登记及复习产物规则沿用原设置。

模型优先使用相关知识点，外部补充独立成段。后端核对来源ID及摘录；解释依据匹配兼容 PDF 换行、空白和 Unicode 连字。有效引用统一标绿，来源校验失败的内容标黄。

「联网补充」默认关闭；开启后调用已有 DeepSeek 搜索接口，每轮一次搜索、最多使用3份正文。模型自身知识可补充其余内容。

按 [DeepSeek 官方文档](https://api-docs.deepseek.com/api/create-chat-completion/)传递推理参数。正文预算按输入和题目数估算为8192—24576 tokens，低 / 高 / 最高推理额外预留8192 / 16384 / 32768 tokens；实际用量取自API返回。请求单并发、单次尝试，使用最近10条历史消息。

长回答到达上限时保留完整段落并提示继续；多道选择题核对返回题号并列出待答题号。诊断快照记录原始响应、用量、检索问题、知识点和联网资料，解析失败记录在 `90_日志/chat-errors/`。
