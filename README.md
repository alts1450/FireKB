# FireKB · 面向强引用学科的可溯源 AI 学习库

**版本 1.0.0**

FireKB 将教材、规范、课件与课堂录音整理成可核验的复习材料。知识点关联来源文件、页码与引用原文，适用于工科、法学、医学等需要精确引用的学科。

## 主要功能

| 环节 | 功能 |
| --- | --- |
| 资料整理 | 按科目归档教材、规范、课件、练习题和课堂录音。支持 PDF、PPTX、EPUB、DOCX 解析、扫描页 OCR 和音频转写。 |
| 知识点提取 | 按课程与章节提取知识点，记录定义、数值、公式、来源和原文摘录。 |
| 引用核验 | 对照原文核对引用和数值，按核验状态浏览条目，并查看待确认事项。 |
| 复习材料 | 按科目生成章节速览、背诵卡、数字对照表和 Anki 导入文件。 |
| 模型配置 | 在桌面端配置本地模型或云端 API，测试连接并管理调用设置。 |

## 1.0.0 新增

- **课表归档与课程流程**。编辑或导入 JSON、CSV、ICS 课表，按日期、时间和课程时段匹配录音等素材。在「处理控制」按科目运行解析、转写、抽取、核验和复习资料生成。
- **知识库问答**。选择课程范围、模型和推理强度，围绕已核验知识点提问与追问。引用内容标绿，悬停可查原文。外部补充标黄，可按需开启联网检索。
- **划选回答并收录**。选中一句、半句或跨段文字，填写标题、正文与批注，保存到指定科目。选中公式时保留 LaTeX。
- **人工核验与 AI 联网自查**。在浏览区查看原文并确认核验，也可用 Flash 按批次核对待确认条目。自查可设置条数与预算，结果附带证据评分和来源。
- **知识点编辑与批量删除**。修改标题、正文、批注、数值、重要度和章节。可逐条勾选、选择本页或选择当前筛选结果，支持跨页选择。保存和删除时自动备份。
- **ZIP 导入导出**。按单科或全科打包 Markdown、知识点数据和引用证据，可附带引用源文件。导入可恢复知识点与包内源文件，按编号跳过已有条目。
- **课程阅读版与打印版**。生成可搜索的 HTML 阅读版和课程 PDF。公式采用 LaTeX 排版，双栏打印版配有页码目录和书签。

## 快速开始

在 Windows 上准备 Python 3.12 和 Node.js。使用录音转写时，将 FFmpeg 加入 `PATH`。

从项目根目录执行以下命令。

```powershell
py -3.12 -m venv .venv
.\.venv\Scripts\python.exe -m pip install -r requirements-full.txt
.\.venv\Scripts\python.exe -m firekb init
npm --prefix firekb-desktop ci
.\启动FireKB桌面端.cmd
```

1. 在「课表设置」录入或导入课表，再到「素材输入」选择文件或文件夹并归档。
2. 在「模型配置」选择文本模型，然后在「处理控制」选择科目并运行课程流程。
3. 在「结果输出」浏览、核验和编辑知识点，生成复习材料或导出 ZIP。
4. 在「知识对话」按课程提问，将有用的解释划选收录。
